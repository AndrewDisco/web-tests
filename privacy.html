Privacy Policy

Last updated: September 29, 2026

Hermes is a private, single-user AI assistant operated by Andrei Dragos (andreidaviddragos@gmail.com). This application connects to the owner's own Google account (Gmail, Calendar, Drive, Contacts) via Google OAuth.

What data is accessed

  • Gmail messages (read, send, modify) — only the owner's own mailbox
  • Calendar events — only the owner's own calendars
  • Drive files and Contacts — only the owner's own data

What happens to the data

  • All data is processed solely for the account owner's personal benefit, at their own request.
  • No data is sold, shared, or transferred to third parties.
  • No data is used for advertising or model training.
  • Data stays within the owner's own infrastructure and Google's own services.

Data deletion

Access can be revoked at any time from Google Account permissions, which immediately removes all API access. Stored tokens are deleted upon revocation.
